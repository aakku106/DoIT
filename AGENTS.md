# DoIT

Go CLI todo app backed by SQLite (WASM-based via `ncruces/go-sqlite3`). Four logical tables: `todos`, `completed`, `trash`, `ignored`.

## Build & Run

```bash
# Build
go build -o doit ./cmd/todo

# Dev build (installs as xdoit to ~/go/bin/)
./dev-build.sh

# Run without building
go run ./cmd/todo add "buy milk"
go run ./cmd/todo list
```

## Code Generation

SQL query layer is generated by `sqlc`. After editing SQL files, regenerate:

```bash
sqlc generate
```

- Source of truth: `sql/schema.sql` (tables) and `sql/queries.sql` (queries)
- Output: `internal/store/` — **never hand-edit generated files**
- Config: `sqlc.yml`
- The schema is embedded into the binary via `sql/assects.go` using `//go:embed`

## Architecture

```
cmd/todo/main.go          — Entrypoint, arg routing
internal/cli/commands.go  — Command handlers (AddTodo, ListTodos, DoneTodo, etc.)
internal/cli/utlitues.go  — ANSI color/style constants
internal/db/sqlite.go     — DB connection; walks up directories to find .doit/
internal/store/            — Generated by sqlc (db.go, models.go, querier.go, queries.sql.go)
internal/todo/service.go  — Stub Service struct, not yet wired in
sql/assects.go            — Embeds schema.sql as SchemaSQLite
```

DB connection (`db.NewSQLite`) looks for a `.doit/` directory starting from cwd and walking upward. The `doit init` command creates `.doit/doit.db`.

## Important Quirks

- IDs in CLI are **display indices** (0-based list position), not DB row IDs. The code maps them via `ListTodoIDs`/`ListCompletedIDs` etc.
- `session` column exists on all tables but is hardcoded to `"todo"` everywhere. Multi-session support is stubbed but not implemented.
- `sessionCall(args)` in `cmd/todo/session.go` is an empty placeholder.
- `migrations/001_init.sql` is stale — runtime uses the embedded schema from `sql/schema.sql` instead.
- No tests or linter config exist in the repo. CI is only the GoReleaser release workflow (see below).
- `temp/` contains experimental sandbox code, not part of the app.

## Release & Distribution

- `.goreleaser.yaml` cross-compiles the `doit` binary for Linux, Windows, and macOS on `amd64`/`arm64` (`CGO_ENABLED=0`, `-s -w`), archives as `tar.gz`/`zip` (Windows) including the manpage and `LICENCE`, and publishes a Homebrew formula to the `aakku106/homebrew-tap` repo (installs binary + manpage).
- `.github/workflows/release.yml` triggers GoReleaser on **tag pushes matching `v*`** (`goreleaser release --clean`). Needs `GITHUB_TOKEN` and `HOMEBREW_TAP_TOKEN` secrets.
- Release flow: tag a commit `vX.Y.Z`, push; workflow builds, attaches archives to the GitHub release, and updates the Homebrew tap.
- Manpage: `docs/man/doit.1` (for package manager / brew manpage install).
